# KBC Mobile — Start screen replica

Interactive replica of the **KBC Mobile** banking app start screen (home dashboard).

## Run

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## What’s included

- Kate search bar (ask / mic)
- Profile avatar with Kate Coins
- Discreet mode (hide amounts)
- **For you** personalised cards
- Swipeable favourite **account** cards
- Latest transactions (show/hide)
- Actions, cards, insights & news
- Additional services (4411, NMBS, Kinepolis, …)
- Personalise start screen CTA
- Bottom nav: Start · Payments · My KBC · Offer

Demo data only — not affiliated with KBC.
